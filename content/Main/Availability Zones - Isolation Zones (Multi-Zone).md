 Additionally to [[Multi Region Cloud Deployment (Multi-Region)]], with Multi-Zone we can spread our system resources across multiple zones. Each zone provides isolation guarantees when it comes to power supply and connectivity. By spreading our application or database instances across multiple zones, if one zone loses power or internet connection, our system can continuing operations as if nothing happened.
